# ProductFaker

ProductFaker is an open-source project designed to test the feasibility of using a product faker in your game. It provides a script to simulate and validate the product faker's functionality, helping you determine if it can be effectively integrated into your game environment.

## Install

1. Clone the repository to your local machine:
   ```sh
   git clone https://github.com/yourusername/ProductFaker.git
   ```
2. Navigate to the project directory:
   ```sh
   cd ProductFaker
   ```
3. Ensure you have Lua installed on your system. If not, download and install it from [Lua's official website](https://www.lua.org/download.html).

## Use

1. Open the `test_product_faker.lua` file in your preferred text editor or IDE.
2. Add your test logic within the `test_product_faker` function to simulate and validate the product faker's functionality.
3. Run the script using Lua:
   ```sh
   lua test_product_faker.lua
   ```
